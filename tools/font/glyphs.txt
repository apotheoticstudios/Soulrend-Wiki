// Soulrend MC: an original pixel serif drawn for the wiki, in the spirit of Times-style book faces.
// Every glyph here was drawn by hand on this grid; nothing is traced from another font.
//
// Format: "== <char>" or "== U+XXXX" starts a glyph, then one line per pixel row ('#' on, '.' off).
// Glyphs list rows 0-6 (cap height, row 6 sits on the baseline) and optionally rows 7-8 (descenders).
// All rows of a glyph have the same length; that length is the glyph width, advance = width + 1.
// "== mark:<name>" defines an accent; build-time composition places it (see tools/lib/bitmap-font.mjs).
// Accented letters (À, ç, ő, ...) are composed from these automatically and need no entry.
// Bold, italic and bold italic are generated from the same drawings (see "Italic letterforms").
//
// Style rules: 1px strokes; outward serifs on paired stems, full serifs on single stems;
// lowercase stems get a top-left entry serif; caps 5-7 wide, lowercase 3-6, figures 5.
