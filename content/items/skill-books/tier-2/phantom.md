**Phantom** is a Dodge skill from EpicFight-Resurrection. A [[item:epicfight:skillbook]] carrying it teaches it; in the [[progression/side-chapters/epic-fight|Epic Fight]] quest chapter it is a Tier 2 book.

## Usage

> [!LORE] Skill tooltip
> Teleport in a specified direction. Dodge all dodgeable attacks.
>
> (Stamina: 4)

Right-click the book and press **Learn**, then equip the skill in the **Dodge** slot of the Skill Editor (**K** by default). It replaces the dodge, which is on **Left Alt** by default. It uses stamina.
