**Parrying** is a Guard skill from Epic Fight. A [[item:epicfight:skillbook]] carrying it teaches it; in the [[progression/side-chapters/epic-fight|Epic Fight]] quest chapter it is a Tier 2 book.

## Usage

> [!LORE] Skill tooltip
> Allows a player to time guards accordingly to prevent stamina use. Player is able to guard against ranged attacks.

Right-click the book and press **Learn**, then equip the skill in the **Guard** slot of the Skill Editor (**K** by default). It replaces the guard, used by holding **right mouse** with a weapon that can guard. The skill only applies to these weapon categories: Amethyst Rapier, Claws, Enderite Rapier, Evil Tachi, Florett, Dual Tachi, Greatsword, Hollow Longsword, Horus Fang, Iron Fist, Katana, Light Greatswords, Longsword, Nova, Oceanite Rapier, Phantom Katana, Poleblade, Rapier, Ritual Daggers, Enhanced Greatsword, Enhanced Longsword, Enhanced Spear, Enhanced One-handed Sword, Enhanced Tachi, Sickles, Spear, Sword, Tachi, Uchigatana, Witherite Rapier, Yamato. It uses stamina.
