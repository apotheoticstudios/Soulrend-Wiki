**『Parry』** is a Guard skill from EpicFight Nightfall. A [[item:epicfight:skillbook]] carrying it teaches it; in the [[progression/side-chapters/epic-fight|Epic Fight]] quest chapter it is a Tier 3 book.

## Usage

> [!LORE] Skill tooltip
> Enhanced parrying

Right-click the book and press **Learn**, then equip the skill in the **Guard** slot of the Skill Editor (**K** by default). It replaces the guard, used by holding **right mouse** with a weapon that can guard. The skill only applies to these weapon categories: Amethyst Rapier, Axe, Claws, Enderite Rapier, Evil Tachi, Florett, Greatsword, Hollow Longsword, Horus Fang, Light Greatswords, Longsword, Oceanite Rapier, Poleblade, Rapier, Ritual Daggers, Sickles, Spear, Sword, Tachi, Uchigatana, Witherite Rapier. It uses stamina.
