**Aurora's Grace** is a bow from Too Many Bows. It is weapon 35 of 35 in [[items/weapons/archery-armory|Archery Armory (Weapons)]], a Pursuit of Mastery quest chapter.

## Obtaining

It is crafted (see [[#Crafting]]).

## Stats

| Stat | Value |
| --- | --- |
| Pull Time (s) | 1 |
| Cast Time Reduction | +40% |
| Draw Speed | +160% |
| Projectile Damage | +24 |
| Spell Power | +0.8 |
| Targets per swing | 1 |
| Durability | 950 |
| Enchantability | 20 |

## Usage

It needs both arrows and a [[item:too_many_bows:rift_shard]] to fire; without a Rift Shard it refuses to shoot.

## Moveset

Epic Fight treats it as a ranged weapon, so it has no melee combo.
