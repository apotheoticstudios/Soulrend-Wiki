## Usage

The Darknight Pursuiters fight with their own combo system, explained by the passive skill's tooltip. It separates a **normal attack** (N) from a **heavy attack** (H), so Epic Fight Awaken recommends binding them to different keys. Its techniques:

| Technique | Input |
| --- | --- |
| Normal attack | N N N N |
| Heavy attack | H H H H |
| Nightfall | N H |
| Dust Reaver | N N H |
| Phantom Dance | N N N, then H repeatedly |
| Shadow Lunge | Dash, N H H H |
| Falling Shadow | Jump, N H |
| Shadow Step | Skill 1 after an attack, then H |

The skill describes the style as an assassin who dodges enemy strikes and strikes back.
