**Void Forge** is a greathammer from cataclysm. It is weapon 58 of 58 in [[items/weapons/heavy-load|Heavy Load]], a Pursuit of Mastery quest chapter.

## Stats

| Stat | Value |
| --- | --- |
| Attack Damage | 23 |
| Attack Speed | 1.60 |
| Impact | 2.5 |
| Targets per swing | 6 |
| Armor Negation | 5% |
| Entity Reach | 3 |
| Enchantability | 16 |
| Fire resistant | Yes |

## Usage

Cataclysm makes it a pickaxe as well as a weapon. With it in the main hand, right-clicking a block summons Void Runes in a fan shape.

## Moveset

In Epic Fight it is a greatsword. Its default Two Handed style has an eleven-hit basic combo and the innate skill True Wrath. It has two other styles, shown below.
