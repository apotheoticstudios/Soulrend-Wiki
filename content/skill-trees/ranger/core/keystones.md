The **Ranger core keystones** are five nodes, of which a player can take at most three. Each one can only be learned by a player who has picked up a [[item:nether_remastered:seal_crystal]] at least once. Each keystone costs 1 point and connects directly to the Ranger node.

{{skilltree ranger focus="ranger_10, ranger_11, ranger_12, ranger_13, ranger_14"}}

## Keystones

| Effect |
| --- |
| +10% Arrow Velocity (total) |
| +15% Arrow Damage (total) |
| ×1.1 Crit Damage with a ranged weapon in hand |
| ×1.1 Crit Chance with a ranged weapon in hand |
| +15% Draw Speed (total) |
