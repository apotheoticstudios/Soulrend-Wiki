**Quickdraw** is one of the four branches of the [[skill-trees/ranger/hexshot|Hexshot]] subclass of the Ranger tree. The name is the wiki's; in game the hub is titled "Notable". It takes 6 points from the Hexshot node to reach its hub, which gives +15% Draw Speed. Three leaves branch off the hub, one point each.

Its nodes give Draw Speed.

{{skilltree ranger focus="ranger_85"}}

## Nodes

The Points column counts the points spent in this branch to reach a node, starting from the Hexshot node. Path nodes must be taken in order; each leaf needs only the hub.

| Node | Points | Effect |
| --- | --- | --- |
| Path ×5 | 1–5 | +2.5% Draw Speed (each) |
| **Hub** | 6 | +15% Draw Speed |
| Leaf | 7 | +15% Draw Speed |
| Leaf | 7 | +15% Draw Speed |
| Leaf | 7 | +20% Draw Speed (total) while crouching |

## Totals

Taking all 9 nodes (9 points) gives:

- +57.5% Draw Speed
- +20% Draw Speed (total) while crouching
