The **Mage Mind keystones** are six nodes, of which a player can take at most two. Each one can only be learned by a player who has picked up a [[item:nether_remastered:seal_crystal]] at least once. Each keystone costs 1 point and connects directly to the Mage node.

{{skilltree mage focus="mage-ks_defense, mage-ks_defxoff, mage-ks_offense, mage-ks_offxutil, mage-ks_utility, mage-ks_utilxdef"}}

## Keystones

| Effect |
| --- |
| +20% Spell Resistance |
| +10% Cast Time Reduction |
| +10% Max Mana |
| +0.5 Armor per 300 current mana |
| +10% Cooldown Reduction |
| +15% Mana Regeneration |
