**Released:** Jun 19, 2025

More quests, an enchantment limiting system and better performance.

## Gameplay Changes

- Added an enchantment limiting system and an option to manually pick up items.
- Added more introduction quests, and quests for The Otherside, Aquamirae, Soulslike Weaponry and Factions.
- Tweaked some quests and chapters.
- Decreased the mob leveling scale and made structures somewhat rarer.
- Added Epic Fight integration for Delightful and Livestock Overhaul.
- Added extra Excalibur support for Paragliders and Dungeons and Combat.
- Removed mod names from item tooltips for integration.

## Backend Changes

- Improved FPS and TPS performance.
- Cleaned up config files.
- Updated mods.

### Mods and resource packs

**Added:** Small Ships, Wizard Samurai, AllTheLeaks (Memory Leak Fix), Noisium, Structure Layout Optimiser, Xenon, Faster Random, JEI + addons, Particle Effects Reforged, Item Banning, Armor Trim Compat, All The Trims

**Removed:** Enhanced Celestials (unnecessary), Yung's Cave Biomes (unnecessary), Second Chance (unnecessary), Embeddium (replaced), Chloride (Embeddium++) (replaced), EMI + addons (replaced), DarkSmelting (unnecessary), Structure Credits (unnecessary), Extra Compat (unnecessary), Double Doors (duplicate feature), Item Obliterator (replaced)
