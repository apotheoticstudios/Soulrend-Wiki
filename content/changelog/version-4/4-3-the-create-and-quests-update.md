**Released:** May 30, 2025

Added Create and quests for the new structure mods. The notes warn that world generation may become corrupted, so worlds should be backed up first.

## Gameplay Changes

- Added quests for Integrated Villages and Towns & Towers.
- Added Simply Swords quests.
- Added Excalibur texture support for Create.
- Reverted several mobs to their default models.

## Backend Changes

- Tuned world generation amplification.
- Refreshed bundled mods.

### Mods and resource packs

**Added:** Create, Integrated Dungeons and Structures, Integrated Villages, Integrated Cataclysm

**Removed:** Via Romana, Visuality: Reforged, Valhesia Structures, Valhelsia Furniture, Strayed Fates: Forsaken, ATi Structures
