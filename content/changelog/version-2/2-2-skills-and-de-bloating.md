**Released:** Apr 7, 2025

Made skill points harder to earn and removed bloat.

## Gameplay Changes

- Skill points scale upward, making them harder to earn.
- Added passive skill tree additions and mob kill points for the passive skill tree.
- Added Shifu, which makes Epic Fight skill books craftable.

## Backend Changes

- Updated mods.

### Mods and resource packs

**Added:** Shifu, passive skill tree additions, passive skill tree mob kill points

**Removed:** Advanced Netherite (unnecessary), Excalibur | Advanced Netherite Support (unnecessary), YDM's Weapon Master (caused visual bugs), Epic Fight: Fighting Styles (unnecessary), Dave's Potioneering (unnecessary)
