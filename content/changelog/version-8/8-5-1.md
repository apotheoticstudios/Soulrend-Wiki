**Released:** Oct 20, 2026  
**CurseForge title:** Performance, Performance, Performance

Performance, Performance, Performance: a faster pack with a revamped video settings menu.

## Gameplay Changes

- Massive performance improvements (tested in a specific environment) (IamFeelix): about 50% faster initial load times, 40% faster server load times, +25% FPS, +22% TPS, +100% FPS on heavy chunk load and +130% 1% FPS lows.
- Revamped the video settings menu with performance presets and less cluttered menus (IamFeelix).
- Moved the Nightlord boss to the Past dimension.
- New class: Beast Master (+15% battlestaff melee damage, +30% damage dealt by all owned summons).
- Reworked the Wood Elf and Pixie origins, and the Hunter class: the starting quiver holds 32 normal arrows.
- Reworked the Feral Beast origin and added the exclusive Wildheart class (Feral Beast is now Feral/Wildheart).
- Changed lifesteal on the Reaper to only recover health on kill.
- Fixed innumerable typos and naming bugs, the skill tree showing id names, several broken quests, Corrosid and Orc being unable to use the Estus Flask, and Pixie hovering across dimension changes.

## Backend Changes

- LootJS was removed. Loot rules, boss damage limits and stat bonuses moved into config/soulrend_core.
- Tags and tag structure were overhauled to use data instead of scripts, then all ported to The Config of Alexandria.
- Equipment recipes were moved into a Soulrend datapack, and a KubeJS pass now uses Soulrend Core instead of commands for performance.
- Origins and classes were centralized and then ported to the Soulrend Origins mod, with the data moved to Paxi. A /soulrend debug command now requires admin (level 2) to prevent log spam.
- Data was restructured, config backups moved to a new folder, a duplicate datapack was deleted, and duplicate scripts cleaned up. Fixed about 25 errors on load (tested on a local server).
- Added issue templates and a contributor workflow, linking the development board and release milestone.
- Updated mods.
