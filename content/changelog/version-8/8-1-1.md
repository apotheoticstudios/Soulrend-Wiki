**Released:** May 27, 2026  
**CurseForge title:** Small Fixes and New Skill Formula

Small fixes and a new skill point formula.

## Gameplay Changes

- Replaced the skill point progression curve with a new formula that starts from a base of 30, so the points needed for each level ramp up more gently.
- Rebalanced several skill tree nodes (Canuckle Headed Viking) and balanced several spells.
- Blocked buying skill points with XP.
- Significantly decreased Sea Serpent leveling.

## Backend Changes

- Updated mods.
