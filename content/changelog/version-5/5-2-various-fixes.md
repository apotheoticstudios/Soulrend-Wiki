**Released:** Sep 1, 2025

Skill tree rebalancing and quest repairs.

## Gameplay Changes

- Scythes now use the glaive attack style.
- Greatly reduced Alchemist skill bonuses and rebalanced parts of the skill tree.
- Adjusted and repaired several quests.
- Some passive creatures can no longer gain levels, and mobs no longer spawn equipped with legendary weapons.
- Fixed missing textures and a spellcasting animation bug.

## Backend Changes

- Refreshed mod versions.

### Mods and resource packs

**Added:** Citadel Fix

**Removed:** Integrated Simply Swords (unnecessary, slowed load times)
