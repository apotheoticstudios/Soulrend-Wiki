**Released:** Sep 4, 2025

Performance work and a higher mob level cap.

## Gameplay Changes

- Raised the mob level cap to 200 and changed how leveling works.
- Stopped several mobs from gaining levels.
- Improved drop rates for Nether Remastered mysterious shards.

## Backend Changes

- Various performance improvements.
- Implemented the patched skill tree correctly.
- Updated mods.

### Mods and resource packs

**Added:** Enhanced Block Entities, AsyncParticles, Village Spawn Point, Explorer's Compass

**Removed:** Bocchium (unnecessary), Better FPS - Render Distance (lowered FPS at smaller render distances), Particle Core (replaced)
