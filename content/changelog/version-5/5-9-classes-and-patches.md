**Released:** Sep 30, 2025

Spellblade and Nature Mage classes, and class bonuses on all equipment.

## Gameplay Changes

- Added a Spellblade and a Nature Mage class (credit: Morak720).
- Made all equipment work with class bonuses (credit: Morak720).
- Added an Affix Enchanting quest chapter and edited several quests (credit: Odd_Turtle).
- Added a prologue quest for changing Origin and Class.
- Made shard quests repeatable and raised the maximum skill points.
- Stopped phantoms from spawning.

## Backend Changes

- Cleaned up datapacks.
- Updated mods.
