**Released:** Sep 20, 2025

New classes and a new main questline.

## Gameplay Changes

- Added new classes.
- Added a new main questline (credit: Odd_Turtle).
- The Pixie origin can now fly.
- Modified several origins and removed the Valkyrie undead slowness debuff.
- Nerfed parts of the mage and blacksmith skill trees and reduced the luck aptitude.
- Fixed excessive cooldown reduction in the magic aptitude and several skill tree bugs.
- Fixed the effect overlay in the Curios menu.

## Backend Changes

- Improved FPS performance and cleaned up config files.
- Fixed Epic Fight mob compatibility issues, fresh animation bugs and texture overrides.
- Fixed a Storage Proxy texture crash (thanks to Ruseki).
- Updated mods.

### Mods and resource packs

**Added:** Vein Mining, Create: Storage, Alex's Mobs, Flerovium, Double Doors, Moog's End Structures, Gods & Heros RPG Classes

**Removed:** Warrior Rage (unnecessary)
