**Released:** May 7, 2025

Five new classes and a reworked difficulty system.

## Gameplay Changes

- Added 5 new classes.
- Added a starting message prompting players to switch to battle mode.
- Reworked the difficulty scaling system.
- Replaced the loading screen (credit: Taknax).
- Removed the Terralith message shown on first join.

## Backend Changes

- Cleaned up some config files.
- Updated mods.

### Mods and resource packs

**Added:** BrassAmber BattleTowers, Advanced Compass, YDM's Mob Healthbar, STRAYED FATES: Forsaken, Gateways to Eternity, Callable Horses, Redirected, HT's Treechop, Furnish, Starter Kit, Euphoria Patches, DeathFX, Item Highlighter, Twilight Treehouses, Armor Curve, Majrusz's Progressive Difficulty, Majrusz's Progressive Difficulty: Chaos Integration

**Removed:** RPG-HUD, Alternative Current (unnecessary), Clean Swing Through Grass (redundant), Death Knell (unnecessary), Rare Ice (unnecessary), Cataclysmic Tunes (unnecessary), CTOV - Paragliders Compat (redundant), Legendary Tooltips (redundant), Panda's Falling Trees (replaced; caused bugs), DC Classes (replaced), Epic Fight - Sword Soaring (caused tag bugs and longer launch times), Epic ACG (unnecessary; caused longer launch times), Dark Mobs - Progressive Difficulty (replaced)
