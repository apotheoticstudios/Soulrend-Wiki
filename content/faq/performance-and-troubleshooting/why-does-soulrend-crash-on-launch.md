The first launch always crashes because of the Epic Fight configuration. Launch the pack again after the first crash. If it keeps crashing, try these:

- Update to the latest release. Most issues are fixed this way.
- Don't restore mods that the game "deleted" after a crash. If you did, reinstall the pack.
- Use JDK 17. Newer Java versions, such as JDK 25, need newer versions of Forge.
- Use a proper launcher, such as CurseForge.
- Close the CurseForge app once Minecraft has started, because it uses many resources.
- On a laptop with two GPUs, make sure Minecraft uses the dedicated one (Task Manager shows which).

If none of that helps, see [[faq/performance-and-troubleshooting/what-should-i-send-when-the-game-crashes|What should I send when the game crashes?]].
