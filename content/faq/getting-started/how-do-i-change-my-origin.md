Right-click the [[item:origins:orb_of_origin]], which the Prologue quest [[progression/prologue/origin-and-class|Origin and Class]] gives you. It reopens the [[features/character/origin-selector|Origin Selector]] so you can pick a race and a class again. The quest gives one orb and the quest text says it can be used only once.

On a server or in a world with cheats, an operator can reopen the selector for any player with `/origin gui <player>`, or set a race or class directly. See [[features/commands/origin-command|/origin]].
