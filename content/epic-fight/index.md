**Epic Fight** is the combat mod at the heart of Soulrend. It replaces Minecraft's click-to-swing fighting with animated movesets: every weapon has combos, dash and jump attacks, a guard and a special move, and players dodge, guard and parry with stamina. Add-ons such as Weapons of Miracles, EpicFight Nightfall and Epic Fight Extra add more movesets and skills, and Soulrend's own datapack assigns them to the pack's weapons.

## Controls

| Action | Default key |
| --- | --- |
| Attack (combo) | Left mouse |
| Innate skill | Hold left mouse |
| Guard / parry | Right mouse |
| Dodge | Left Alt |
| Mobility skill | Space |
| Lock-on | Middle mouse |
| Skill Editor | K |
| Shield parry (Soulslike Weaponry) | Right Alt |

Epic Fight has a **battle mode** and a **mining mode**. Its toggle key is unbound in Soulrend; set it in Controls to switch to mining mode, where the left mouse button breaks blocks normally.
