**Commands Features** covers the chat commands that matter in Soulrend. Most commands that change a character (level, origin, skill tree) are **operator** commands: they need permission level 2, which means operator status on a server or cheats enabled in singleplayer. Party, claim and graphics commands work for every player.

| Command | Who | Used for |
| --- | --- | --- |
| [[features/commands/soulrend-command\|/soulrend]] | Operator | Soulrend levels and skill points, silent command runs, debug dumps. |
| [[features/commands/origin-command\|/origin]] | Operator | Reading, setting or re-picking a player's race and class. |
| [[features/commands/skilltree-command\|/skilltree]] | Operator | Adding skill points, resetting trees, granting skills. |
| `/oparties`, `/oclaims` | Everyone | Open Parties and Claims parties and land claims. |
| `/ftbteams party` | Everyone | Quest-sharing teams. |
| `/fsoclient` | Everyone | Graphics presets and performance settings. |
| `/waystones`, `/deathhistory`, `/chunky` | Operator | Waystone lists, death locations, terrain pre-generation. |
