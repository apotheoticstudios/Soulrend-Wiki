The **official servers** for Soulrend are run by **Craft Down Under** (CDU) in three regions. They share one character: inventory, skills and quest progress follow the player from one region to another, so anyone can play on the server closest to them and still join friends elsewhere.

**Server page:** [craftdownunder.co/servers/souldrend](https://craftdownunder.co/servers/souldrend?query=SOULDREND)

## How it works

| Region | Area | Address |
| --- | --- | --- |
| AU | Oceania | `soul.au.playcdu.co` |
| EU | Europe | `soul.eu.playcdu.co` |
| US | North America | `soul.us.playcdu.co` |

The modpack includes the **Soulrend Companion** mod, which replaces the Multiplayer screen with an **Official Soulrend Realms** menu:

1. Click **Multiplayer** on the title screen. The realms menu lists the three regions with their status.
2. Pick a region to join it. The menu remembers the last region played.
3. To change region later, open the pause menu and press **Switch region**. The same character carries over.

**Other servers** opens the normal server list. **Don't show again** makes the normal list open by default; its **Official realms** button brings the realms menu back.

## Details

- **Free to play.** CDU's server page describes the servers as free, with no pay-to-win.
- **Version.** Join with the same modpack version the server runs; download it from CurseForge, linked on the server page.
- **Rules and community.** The server page links CDU's rules, forum and Discord ([discord.gg/playcdu](https://discord.gg/playcdu)).
- **Claims and parties** work as described on [[features/multiplayer/teams-and-claims|Teams & Claims]], though the official servers use their own limits.
- If the realm list can't be reached, the menu shows the last known list and keeps retrying.
